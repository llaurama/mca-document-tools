About repayment patterns

Daily payments post on business days; weekly payments post on Wednesdays. Obfuscated payments combine differently sized obligations, drifting dates, occasional one-offs, and a possible lump sum to test payment-frequency inference. A financing posts through its selected stop month.

Debt collectors

Each collector gets one ACH debit per month. Names and payment amounts stay the same across the set. Random selects distinct agencies.

Testing & reproduction

Break modes alter only the latest statement.

About reconciliation breaks

Misstated changes one printed transaction amount while retaining the true totals. Unlisted balance shift changes the printed ending balance and daily balances without a matching transaction. Both create an intentional mismatch for reconciliation testing.
